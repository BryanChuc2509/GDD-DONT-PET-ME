# Criterios de Calidad

## Descripción de la sección

Define qué significa que una característica esté correctamente terminada.

## Calidad funcional

- [ ] Funciona según las reglas documentadas.
- [X] No produce errores conocidos críticos.
- [ ] Maneja casos límite importantes.

## Calidad de experiencia

- [X] El jugador entiende el objetivo.
- [X] Las respuestas del juego son claras.
- [X] La dificultad es coherente.
- [X] La interfaz es comprensible.

## Calidad técnica

- [ ] Rendimiento aceptable.
- [X] Sin errores críticos.
- [ ] Guardado estable.
- [ ] No existen dependencias rotas.
