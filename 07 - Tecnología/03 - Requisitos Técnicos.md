# Requisitos Técnicos

## Descripción de la sección

Define las condiciones técnicas necesarias para ejecutar y desarrollar el videojuego.

## Requisitos mínimos

Los mínimos propuestos permiten ejecutar el juego en un PC modesto, con gráficos 3D sencillos y resolución HD.

## Requisitos recomendados

Para una experiencia más fluida y una presentación Full HD, se recomiendan las siguientes especificaciones:

| Componente | Mínimos | Recomendados |
| --- | --- | --- |
| Sistema operativo | Windows 10 (64 bits) | Windows 11 (64 bits) |
| CPU | Intel Core i3 de 8.ª generación o equivalente | Intel Core i5 de 10.ª generación o equivalente |
| GPU | Intel UHD 630 o equivalente | NVIDIA GTX 1050 o equivalente |
| RAM | 4 GB | 8 GB |
| Almacenamiento | 2 GB disponibles | 4 GB disponibles |
| Resolución | 1280 × 720 (HD) | 1920 × 1080 (Full HD) |
| Conexión | No requerida | No requerida |

## Objetivos de rendimiento

| Parámetro | Objetivo propuesto |
| --- | --- |
| FPS mínimos | 30 FPS estables |
| FPS objetivo | 60 FPS estables |
| Tiempo de carga inicial | Menos de 15 segundos |
| Carga entre niveles | Menos de 5 segundos |
| Memoria RAM utilizada | Idealmente menos de 2 GB |
| Tamaño estimado del juego | Entre 500 MB y 2 GB |

## Restricciones

El proyecto es un juego de plataformas 3D lineal y de complejidad visual moderada; no requiere hardware de gama alta ni conexión a internet. Los requisitos y objetivos de rendimiento son las especificaciones propuestas para el alcance actual y deberán comprobarse con una versión compilada en equipos que representen las configuraciones mínimas y recomendadas. El tamaño final puede variar según los recursos incluidos.
