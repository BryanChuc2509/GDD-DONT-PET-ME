# Glosario

## Descripción de la sección

Centraliza términos técnicos, de diseño y propios del universo del videojuego.

| Término            | Definición                                                                                                                                              |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GDD                 | Documento de Diseño de Videojuego.                                                                                                                      |
| Mecánica           | Regla o interacción mediante la cual el jugador puede actuar.                                                                                           |
| Sistema             | Conjunto de componentes y reglas que trabajan juntos.                                                                                                    |
| MVP                 | Producto Mínimo Viable.                                                                                                                                 |
| Vertical Slice      | Muestra pequeña pero representativa del producto final.                                                                                                 |
| Preproducción      | Etapa actual del proyecto: el concepto, el alcance inicial y la mecánica principal ya están definidos, pero todavía no existe un prototipo funcional. |
| Prototipo funcional | Versión jugable mínima con la que se prueba si la mecánica principal es divertida y funciona.                                                         |
| FPS                 | Cuadros por segundo. Objetivo del proyecto: 60 FPS; mínimo aceptable: 30 FPS.                                                                           |
| Unity               | Motor gráfico con el que se desarrolla el videojuego.                                                                                                   |
| Blender             | Herramienta utilizada para crear los recursos 3D.                                                                                                        |
| itch.io             | Plataforma de distribución digital prevista (gratuita o de pago voluntario).                                                                            |
| Estación 05        | Nombre del equipo de desarrollo.                                                                                                                         |
